# Agent Skill 验收记录

## 实现与使用

分支 `feat/pi-agent-skills`。在画布右侧切换 Agent，点击附件旁的 Skill，上传 [wechat-cover/SKILL.md](../skills/wechat-cover/SKILL.md)，选中后添加 Markdown 文章并发送。也可使用 [测试文章](fixtures/wechat-cover-article.md)。第一轮给出主题、短标题及五种风格；回复风格序号即可继续，无需再次选 Skill。

技能仅在当前用户、当前项目可见。标准 UTF-8 SKILL.md 最大64KiB，frontmatter name/description 必填；名称只接受小写字母、数字及单连字符，最长64字符；正文完整保存。列表简介两行省略，悬停可看完整简介。同项目重名返回409。移除只影响技能列表，历史消息快照仍保留。

- Chrome 真实上传 SKILL.md 和文章；列表、选择、发送即清空、下一条无默认技能、刷新恢复消息名称。
- Chrome 另一项目列表为空；本地 PostgreSQL 验证跨用户 RLS、跨项目引用、非法归属插入、幂等请求及删除后快照。

- 首轮真实 Kimi 输出五风格，未调用生图工具；第二轮只输入“3，插画。”，未重新选择技能。
- 106项测试通过，TypeScript、ESLint、生产构建通过；中文 Skill 验证器通过。独立审核未发现阻塞问题。

## 真实联调发现与修复

第一轮生图验收中，首张 GPT Image 2.5 成功后遇到暂时性保存失败，旧逻辑立即阻断后三张；后台稍后将首张保存成功。已保留该项目和结果，不重复提交该收费任务。

修复为在原有7分钟截止时间内继续对同一 generation 同步保存；恢复后继续剩余调用，超时仍阻止新收费提交。回归测试先失败后通过：同一图片仅提交一次，保存恢复后可完成四次调用，第五次被拒绝。独立审核确认现有同步锁和四张上限保留。
