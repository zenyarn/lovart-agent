# Lovart 初步调研

调研日期：2026-11-20。范围为官方公开文档与产品介绍，未登录实测；以下产品能力属于官方描述，内部实现尚未验证。

## 1. 它是什么

Lovart 是面向品牌、营销、电商和社交媒体等场景的 AI 设计 Agent。用户描述需求并提供参考素材，由 Agent 调用生成和编辑工具，把设计产物组织到统一画布中，再通过对话继续修改。[1]

可以将其产品形态概括为：**对话入口 + 设计任务编排 + 多模态工具 + 可编辑画布 + 项目资产管理**。这是根据公开功能做出的产品拆解，不代表其真实内部架构。

## 2. 核心能力

| 模块 | 官方描述的用途 | 对复刻项目的启发 |
| --- | --- | --- |
| 设计 Agent | 根据需求选择图像、视频模型，执行创作任务 [1] | 需要任务状态与工具调用闭环 |
| ChatCanvas | 在无限画布上生成、摆放和编辑产物 [1][2] | 对话需要关联具体画布对象 |
| 局部修改 | 选中区块或图像进行修改；支持 Touch Edit [2] | 需要选区、对象引用和版本关系 |
| Brand Kit | 保存标志、颜色、字体等品牌信息 [2] | 将风格约束作为项目上下文 |
| Skills | 将常见设计任务组织为可复用工作流 [1] | 可先做一个明确场景的固定流程 |
| 导出 | 按产物支持图像、设计文件和视频等格式 [1] | 第一版先明确一种可靠交付格式 |

典型使用过程是：输入需求与参考 → 生成设计 → 在画布检查 → 指定对象修改 → 导出。[1][2]

## 3. 当前产品已扩展到个人设计助手

官方于 2026-10-19 发布的 Lovart 2.0 介绍加入 Arti：保存可管理的个人偏好与常用资产、支持一次性或定时设计委托，并提供设计研究、设计检查、评论驱动修订以及工作流沉淀为技能的能力。[3]

这意味着完整复刻的范围相当大：既涉及设计工作台，也涉及跨项目记忆和后台任务。第一版范围应另行确定。

## 4. 对本项目的初步判断

以下是研究后的建议，尚未作为已确认需求或技术决策。

优先验证一个最小闭环：**输入海报需求与参考图 → Agent 生成图片 → 展示到画布 → 选中图片提出修改 → 保留新旧版本 → 导出 PNG**。

值得优先解决的问题：

- 上下文：Agent 如何理解当前选中的对象、参考图和修改意图。
- 工具执行：生成与编辑耗时较长时，如何呈现进度、处理失败和重试。
- 状态同步：聊天中的执行结果与画布中的对象如何保持一致。
- 可编辑性：整张图片的 AI 修改与独立文字、图层编辑是不同能力，需要明确第一版目标。
- 成本：每次任务涉及多少模型调用，如何限制重复生成。

后续再讨论多模型路由、品牌资产库、视频、定时任务及跨项目记忆。公开资料不足以确认 Lovart 的内部模型编排、存储、画布技术或提示词方案，需自行设计实现。
