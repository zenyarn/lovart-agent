# 公众号封面

## 阅读与确认风格

用户消息中的 Markdown 附件包含全文。阅读从开头到结尾的所有段落，识别主题、目标读者、核心观点和结论，不只依据文件名或标题。若没有文章或内容不完整，先请用户补充。

先用两三句话概括主题，给出一个 4–12 字中文短标题（保留事实，不编造收益、数据或承诺）。然后明确请用户从以下五种风格中选择一种：

1. **极简大字报**：大字、强对比、大留白。
2. **杂志封面**：编辑排版、摄影质感、克制层级。
3. **插画**：主题隐喻、柔和色彩、有故事的画面。
4. **科技**：精确网格、数字光感、未来科技视觉。
5. **孟菲斯**：几何拼贴、活泼撞色、节奏感。

这一轮停下来等用户回答，不调用 generate_image。用户下一条的风格名称或序号是本任务的继续，不需要再次选择 Skill；结合历史文章、标题和用户修改继续执行。用户明确改变任务时遵从新需求。

## 五种风格的执行规范

- 极简大字报：米白/炭黑为主，单一朱红或亮黄强调色；粗黑体中文，标题占视觉主体，禁止密集小字；几何形状只作轻量平衡。
- 杂志封面：暖灰/奶油白/深墨色，低饱和照片或静物主体；中文宋体标题搭配细黑体辅助字，清晰网格与留白；不编造刊号、品牌标志或真实人物身份。
- 插画：奶油白底、鼠尾草绿与珊瑚橙小面积点缀；扁平或轻质感手绘，围绕文章核心做具象隐喻；圆润清晰中文黑体，人物/物体不能挡住标题。
- 科技：深海军蓝与青蓝发光点缀，克制使用银白；精确网格、光轨或数据结构隐喻，不堆砌无意义代码；方正现代中文黑体，保证高对比与可读性。
- 孟菲斯：奶油白底，钴蓝/珊瑚橙/明黄组合；圆、弧线、点阵、折线形成有节奏的几何拼贴；粗黑体或圆体中文，活泼但不压过主标题。

## 选定后同一轮生成四张

使用现有 **generate_image** 工具（后端固定 GPT Image 2.5），调用四次，每次一张；使用 `ratio: "16:9"`、`resolution: "1K"`。不要创建其他生成服务或脚本。除非用户明确要求，不把文章内容做成截图，也不将四张拼成一张。

四张统一短标题、配色、字体与所选风格；通过以下构图区分，分别写完整提示词，不能只说“与上一张一样”：

1. 左侧标题、右侧主题主体，留白清晰。
2. 标题居中，主体/形状环绕，重心稳定。
3. 右侧标题、左侧主题主体，用视线或形状引导。
4. 大字与主题细节形成对角线，空间层次明确。

每个提示词都写明：文章主题、准确短标题文字、所选风格、主辅色、具体主体、构图、字体、留白、无额外乱码/水印。宽幅画面中让标题与关键主体落在中央可安全裁切区域，适配公众号约 2.35:1 裁切；不声称工具直接输出不存在的比例。无参考图片时采用文生图；有用户指定的参考图时先 view_image 实际查看再使用。

四张成功结果会自动进入画布。全部完成后简短说明四种构图差异；只有工具返回 succeeded 才宣称成功。若任务失败或结果待核实，如实报告已完成数量及状态，不擅自重试付费任务或把未完成结果称作四张成品。
